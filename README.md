# GIFARC: Synthetic Dataset for Leveraging Human-Intuitive Analogies to Elevate AI Reasoning

This repository is the official implementation of [GIFARC: Synthetic Dataset for Leveraging Human-Intuitive Analogies to Elevate AI Reasoning]. 

The resultant dataset generated with this project can be found in [Hugging Face @DumDev/gif_arc](https://huggingface.co/datasets/DumDev/gif_arc).

The data demonstration is also visualized in a [webpage](https://gifarc-visualization.vercel.app/).
