# GIFARC pipeline

To generate ARC-style tasks with GIFARC pipeline...

To run the pipeline in this anonymous artifact, place your own GIF files under `data/GIF/` and run `description_executor.ipynb`. The raw GIPHY crawl metadata used for the paper dataset is not included in the review artifact.

Open `description_executor.ipynb` and now run all the ipynb block. It will generate the gifarc data under ./results/

CAUTION: You need to use `Run All` to generate data continuously. If it fails, or you want to use prev data, make sure to designate the new results directory name.
