# Seed Program Provenance

The files in this directory are ARC-style seed programs used by the GIFARC generation pipeline. Some seed files preserve upstream-style identifiers from prior public ARC/BARC seed corpora, including suffixes such as `_Kevin`.

These suffixes are provenance identifiers for upstream seed material. They do not identify this submission's authors, annotators, reviewers, or institution. Keep these filenames stable when regenerating prompts or result traces, because generated JSONL artifacts may refer to seed filenames directly.

When adding new seed programs for this anonymous submission, avoid adding author names, local usernames, affiliations, email addresses, or private dataset paths to filenames, comments, or docstrings.
